Revit MCP connects Claude to the Revit model you have open. Ask in plain language, for example "How many doors are on Level 2?" or "Add a 4 m by 3 m room with a door on Level 1". Claude reads the model to understand it, proposes changes, shows you a preview, and only changes the model after you approve. Every change is one Revit undo step.

Getting started

You needRevit 2025, 2026 or 2027 on Windows 10/11, and Claude Desktop or Claude Code with a Claude plan.
  1. Install Revit MCP. The installer registers it with Claude Desktop and Claude Code if they are installed.
  2. Start Revit and open a project. A Revit MCP tab appears on the ribbon.
  3. Start (or restart) Claude Desktop. In a new chat, ask "Check the Revit connection".

Installed Claude after Revit MCP? Click Revit MCP > Connect Claude in Revit, then restart Claude.

How changes work

StepWhat happens
StageClaude writes a plan (for example: 4 walls, 1 door, 1 room). Nothing changes yet.
PreviewThe plan is checked against your live model: levels, types and hosts are resolved, problems are reported. Nothing changes yet.
ApproveClaude asks you to approve the previewed change. Declining leaves the model untouched.
CommitThe whole plan is applied as one Revit undo step. If any part fails, nothing is applied.
UndoAsk Claude to undo, or use Revit's own Ctrl+Z.

Today Claude can create walls, doors, windows, floors, rooms and levels, and read levels, grids, types, families and elements. It does not edit or delete existing elements.

Privacy and data

  • The Revit add-in listens only on this computer (127.0.0.1). It cannot be reached from the network.
  • Model information that Claude asks for (for example level names, element types, element counts and geometry of the elements it queries) is sent to Claude through your Claude app, under your Claude account and Anthropic's terms. Revit MCP itself sends nothing anywhere else and collects no telemetry.
  • Logs, the audit log and access settings stay on this computer in %LOCALAPPDATA%\RevitMCP.

Access control and audit log

By default the Claude app on this computer may read the model and, after your approval, change it. Administrators can issue read-only or read-write access tokens that expire, and revoke or rotate them, with the bundled tool:

revit-mcp-server.exe auth --help (in %APPDATA%\Autodesk\ApplicationPlugins\RevitMCP.bundle\Contents\Server)

Every commit, undo and refused request is written to a tamper-evident audit log (%LOCALAPPDATA%\RevitMCP\audit\audit.jsonl): who approved, when, how, what changed, in which model.

Troubleshooting

SymptomTry
Claude has no Revit toolsClick Connect Claude, then fully quit and restart Claude Desktop.
"Revit is not reachable"Make sure Revit is running with a project open, and that Status doesn't say Paused.
"Revit is busy"Finish or cancel what you are doing in Revit (an edit mode or an open dialog), then ask again.
A change was refusedThe preview explains why (for example a missing type or level). Ask Claude to adjust the plan.

Support and uninstall

Contact {{SUPPORT_EMAIL}}. Use Status > Copy details and attach the files from Logs.

To uninstall, close Revit and use Windows Settings > Apps > Installed apps > Revit MCP. This also removes Revit MCP from Claude Desktop and Claude Code. Your audit log is kept.
